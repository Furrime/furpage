# FurPage™

一个开源的兽圈（Furry）个人展示站点项目，采用柔和马卡龙配色，支持自定义配置和多种特色功能。

** 此项目不受作者编写代码时使用的码风的漏洞影响，可放心使用 **

## 功能介绍

### 核心基础板块
- **首页** - 个性化欢迎页面，支持轮播图和背景音乐
- **兽设档案** - 详细展示兽设信息，包含证件风兽设卡
- **作品图库** - 展示个人作品，支持分类管理

### 特色专属板块
- **兽装专栏** - 展示兽装相关内容和图片
- **日常随笔** - 记录生活点滴和故事
- **亲友墙** - 展示好友和亲友信息
- **留言板** - 访客留言功能
- **约稿专区** - 展示约稿价格和流程

### 趣味彩蛋功能
- **匿名问答** - 访客可以匿名提问，主人可回复和管理
- **素材下载** - 提供素材下载链接
- **社交跳转** - 链接到其他社交平台
- **时间轴** - 展示个人成长历程

### 管理员系统
- **配置管理** - 配置所有图片、文字和功能开关
- **问答管理** - 回答问题、删除不当言论
- **留言管理** - 发布站长留言、删除不当留言
- **密码修改** - 支持修改登录密码

## 设计特色

- **马卡龙配色** - 柔和低饱和的毛绒色系
- **玻璃态设计** - 透明/磨砂效果的卡片组件
- **动态背景** - 支持自定义背景图片或渐变色
- **响应式布局** - 适配各种屏幕尺寸

## 技术栈

### 前端
- React 18 + TypeScript
- Vite 6
- TailwindCSS 3
- React Router DOM
- Zustand (状态管理)
- Lucide React (图标)

### 后端
- Node.js + TypeScript
- Express 4
- JSON 文件存储

## 快速开始

### 环境要求
- Node.js >= 18.0.0
- npm >= 9.0.0

### 安装与运行

1. **克隆项目**
   ```bash
   git clone https://github.com/Furrime/furpage
   cd furpage
   ```

2. **安装依赖**
   ```bash
   npm install
   ```

3. **配置环境变量**
   ```bash
   cp .env.example .env
   ```
   编辑 `.env` 文件，设置管理员密码和端口。

4. **启动开发服务器**
   ```bash
   npm run dev
   ```

5. **首次初始化**
   - 访问 `http://localhost:3001/admin/init`
   - 设置登录密码（至少4位）
   - 填写基本配置（站点标题、兽设名称等）
   - 点击"完成初始化"按钮

6. **登录管理后台**
   - 访问 `http://localhost:3001/admin/login`
   - 输入设置的密码登录

### 构建生产版本

```bash
npm run build
npm run server:prod
```

## 配置说明

### 首页配置
- **轮播图片** - 上传首页轮播图（建议尺寸：1920x1080）
- **背景音乐** - 支持网易云音乐嵌入或上传本地音频

### 兽设档案配置
- **头像** - 上传兽设头像
- **基本信息** - 名字、物种、性别、年龄等
- **喜好/讨厌** - 用逗号分隔多个标签
- **个人简介** - 详细描述

### 功能开关
- 在管理后台的"功能开关"标签页中可以开启/关闭各个模块

## 安全说明

- 管理后台需要密码登录
- 所有配置数据存储在本地JSON文件中
- 建议定期备份 `api/db/data/` 目录
- 请勿将 `.env` 文件提交到版本控制
